CRONのスケジューリングパターン

Linux

cronのスケジューリングパターンをメモ

# 午前3時に実行
0 3 * * * php /home/surge/hoge.php

# 30分度に実行
0,30 * * * * php /home/surge/hoge.php

# 3時間度に実行
0 */3 * * * php /home/surge/hoge.php

# 毎週月曜日の午前3時に実行
0 3 * * Mon php /home/surge/hoge.php

# 毎月1日の午前3時に実行
0 3 1 * * php /home/surge/hoge.php

#月～金曜日の午前3時に実行
0 3 * * mon-fri php /home/surge/hoge.php

# 1月11日午前1時11分に実行
11 1 1 jan * php /home/surge/hoge.php
